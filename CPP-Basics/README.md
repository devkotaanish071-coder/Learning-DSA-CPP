# CPP Basics 

This folder contains my fundamental C++ programs focusing on language basics.

## Programs Included:
- **01-helloworld.cpp**: Printing Hello World to the console.
- **02-input_output.cpp**: Taking user Name and Age input and printing it.
- **03-odd_even.cpp**: Using if-else condition to check even or odd number.
- **04-largest_3_number.cpp**: Taking 3 number input from user and giving the largest among them.
- **05-leap_year.cpp**: Taking a Year input from user and check whether leap year or not.
- **06-factorial.cpp**: Using for Loop to to find factorial of user inputed number.
- **07-multiplication_table.cpp**: Using for Loop to find multiplication table of user inputed number.
