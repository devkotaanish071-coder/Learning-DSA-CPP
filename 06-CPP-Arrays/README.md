# CPP Arrays

This folder contain basic medium and haed level array problems.

## Programs Included:
* **01-find_largest_element**: Finding laegest element in a 1D array where the array con contain negative numbers also.
* **02-find_second_largest_element**: Finding second largest element in a 1D array which could contain negative numbers with O(n) Time complexity.
* **03-array_is_sorted_or_not**: Taking a user inputed array and finding the array is sorted or not with O(n) Time complexity.
* **04-remove_duplicate**: Removing duplicate from a user inputed array.
* **05-left_rotate_array**: Rotataing a user inputed array by 1 time.
* **06-left_rotate_by_k_element_brute**: Taking a array input and asking for how many time rotate and rotating the array with Time Complexity of O(N+K) and Space Complexity of O(K).
* **07-left_rotate_by_k_element_optimized**: Taking a array input and dividing array from (1,K) then (K,N) and reversing both and after that reversing from (1,N) which make the whole array rotated with Time Complexity of O(2N) and Space Complexity of O(1).
* **08-right_rotate_by_k**: Rotating a user inputed array without using in-built reverse function.
