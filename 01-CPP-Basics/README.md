# CPP Basics

This folder contains my fundamental C++ programs focusing on language basics.

## Programs Included:
* **01-helloworld.cpp**: Prints "Hello World" to the console.
  * **Time Complexity**: O(1)
  * **Space Complexity**: O(1)
* **02-input_output.cpp**: Takes user Name and Age input and prints it back out.
  * **Time Complexity**: O(1)
  * **Space Complexity**: O(1)
* **03-odd_even.cpp**: Uses an if-else condition to check if a number is even or odd.
  * **Time Complexity**: O(1)
  * **Space Complexity**: O(1)
* **04-largest_3_number.cpp**: Takes 3 numbers as input from the user and outputs the largest among them.
  * **Time Complexity**: O(1)
  * **Space Complexity**: O(1)
* **05-leap_year.cpp**: Takes a year input from the user and checks whether it is a leap year or not.
  * **Time Complexity**: O(1)
  * **Space Complexity**: O(1)
* **06-factorial.cpp**: Uses a for loop to calculate the factorial of a user-inputted number.
  * **Time Complexity**: O(N), where N is the inputted number
  * **Space Complexity**: O(1)
* **07-multiplication_table.cpp**: Uses a for loop to print the multiplication table of a user-inputted number.
  * **Time Complexity**: O(1) (since it always loops exactly 10 or 12 times)
  * **Space Complexity**: O(1)
