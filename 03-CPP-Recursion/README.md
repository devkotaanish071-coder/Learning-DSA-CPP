# CPP Recursion

This folder contains recursion challenges designed to master functional self-calling logic and the system call stack.

## Programs Included:
* **01-print_name**: Basic introductory function that prints a name once.
  * **Time Complexity**: O(1)
  * **Space Complexity**: O(1)
* **02-print_name_n_times**: Recursively prints a name exactly N times.
  * **Time Complexity**: O(N)
  * **Space Complexity**: O(N) due to recursion stack depth
* **03-print_1_to_num**: Prints numbers sequentially from 1 up to N using recursion.
  * **Time Complexity**: O(N)
  * **Space Complexity**: O(N) due to recursion stack depth
* **04-print_num_to_1**: Prints numbers backward from N down to 1 using recursion.
  * **Time Complexity**: O(N)
  * **Space Complexity**: O(N) due to recursion stack depth
* **05-sum_of_first_n_number**: Calculates the mathematical sum of numbers from 1 to N recursively.
  * **Time Complexity**: O(N)
  * **Space Complexity**: O(N) due to recursion stack depth
* **06-factorial**: Computes the factorial of N using functional recursion.
  * **Time Complexity**: O(N)
  * **Space Complexity**: O(N) due to recursion stack depth
* **07-reverse_an_array**: Reverses an array using a standard iterative loop approach.
  * **Time Complexity**: O(N)
  * **Space Complexity**: O(1)
* **08-reverse_array_with_recursion**: Reverses an array in-place using recursive two-pointer swaps.
  * **Time Complexity**: O(N)
  * **Space Complexity**: O(N) due to recursion stack depth
* **09-palindrome_of_a_word**: Checks if a single string reads the same forward and backward using recursion.
  * **Time Complexity**: O(N), where N is the length of the word
  * **Space Complexity**: O(N) due to recursion stack depth
* **10-palindrome_of_a_sentence**: Cleans up spaces/punctuation and checks if a full sentence is a palindrome recursively.
  * **Time Complexity**: O(N), where N is the length of the sentence
  * **Space Complexity**: O(N) due to recursion stack depth
