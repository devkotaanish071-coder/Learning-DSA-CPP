# CPP Patterns

This folder contains logic-building challenges designed to master nested loops and coordinate-based printing in C++.

## Programs Included

### 1. Basic Patterns (Basic)
* **01-right_angle_triangle.cpp**: Standard increasing star triangle matching the row index.
  * **Time Complexity**: O(N²)
  * **Space Complexity**: O(1)
* **02-inverted_triangle.cpp**: Decreasing star triangle starting from N down to 1.
  * **Time Complexity**: O(N²)
  * **Space Complexity**: O(1)
* **03-number_right_traingle.cpp**: Increasing number sequence printed in a triangular format.
  * **Time Complexity**: O(N²)
  * **Space Complexity**: O(1)

### 2. Medium Patterns (Medium)
* **04-star_pyramid.cpp**: Centered full pyramid utilizing calculated leading spaces.
  * **Time Complexity**: O(N²)
  * **Space Complexity**: O(1)
* **05-diamond_pattern.cpp**: Symmetrical combination of upright and inverted pyramids.
  * **Time Complexity**: O(N²)
  * **Space Complexity**: O(1)
* **06-floyds_triangle.cpp**: Sequential, continuously running integers across rows.
  * **Time Complexity**: O(N²)
  * **Space Complexity**: O(1)

### 3. Advanced Challenges (Hard)
* **07-hollow_rectangle.cpp**: Boundary-only star tracking using strict conditional logic.
  * **Time Complexity**: O(N * M), where N and M are rows and columns
  * **Space Complexity**: O(1)
* **08-butterfly_pattern.cpp**: Symmetrical side-aligned star wings with shifting central padding.
  * **Time Complexity**: O(N²)
  * **Space Complexity**: O(1)
* **09-number_matrix.cpp**: Advanced concentric shrinking number walls based on boundary distances.
  * **Time Complexity**: O(N²), where the total matrix space printed is (2N-1) * (2N-1)
  * **Space Complexity**: O(1)
